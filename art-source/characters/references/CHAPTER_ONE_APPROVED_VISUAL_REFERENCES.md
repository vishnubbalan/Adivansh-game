## How to use the reference

- Use the image for face identity, hair silhouette, costume colour and broad garment construction.
- Use the individual character production sheets for numerical measurements, Blender object naming, material definitions, rigging and validation requirements.
- The generated turnarounds are visual guidance, not mathematically exact orthographic projections. Build one shared measured blockout mesh per character and render true orthographic front/side/back views from that mesh.
- Resolve any conflict between image text and the detailed production sheets in favour of the approved character identity and explicit owner decisions. Do not silently invent costume details.
- Keep the Indo–East Asian blend in original textile motifs, garment detailing, knots, lacquered fittings and crafted accessories. Avoid stereotypes or direct copying of sacred iconography.

## Production gates

1. **Blockout:** one consistent measured mesh per character; matched front/side/back orthographic renders.
2. **Sculpt/retopology:** facial identity and anatomy preserved; clothing remains separately editable.
3. **Texture/rig:** PBR material review, expression tests, walk/interact animation, cloth and accessory collision checks.
4. **Game-ready proof:** export a standalone GLB test scene, re-import and validate scale, materials, skeleton, deformation and performance before game integration.

No Blender source model, sculpt, retopology, rig, texture bake, GLB or in-game integration is claimed by this approval record.
